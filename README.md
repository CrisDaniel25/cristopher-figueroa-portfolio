# Cristopher Figueroa — Software Engineering Portfolio

Bilingual portfolio and five browser-local engineering simulations.

## Included

- Responsive English / Spanish portfolio landing page.
- Anonymized experience summaries that avoid client or employer names and implementation details.
- Five interactive sample labs: tenant onboarding validation, RBAC permissions, OAuth 2.0 + PKCE flow, bounded background-job queue, and a REST API explorer.
- Fictional data only. The labs do not call a live backend and are not production or client deliverables.
- Static hosting configuration for Netlify.

## Run locally

Open `index.html` in a static web server. No build step or dependency install is required.

## Deploy on Netlify

Connect this repository to Netlify. The site publishes from the repository root as configured in `netlify.toml`.
